# DESIGN.md e receitas (rohitg00/awesome-claude-design)

- `design-md/<família>/<marca>.md`: tokens e regras de marcas reais por família estética. Use como referência de nível, nunca para copiar a identidade de outra marca.
- `prompts/`: roteiros prontos. Os mais úteis para revisão: `audit-live-site.md`, `break-default-aesthetic.md`, `3-designer-debate.md`, `family-picker.md`.
- `recipes/`: passo a passo (landing em 20 min, extrair marca, repo para design system, wireframe para alta fidelidade).
